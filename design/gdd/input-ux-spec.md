# 输入系统 UX 规格 · 双端分离（方案 A）

> 阶段：Phase 5 制作期 / 输入系统重构
> 版本：v1.0 · 2026-11-09
> 适用：Godot 4.7 Web 导出，竖屏 720×1280（portrait）

## 1. 问题与目标

现状：移动、瞄准、开火三者共用同一个鼠标/触摸位置。`main.gd:_input()` 把
`event.position` 写进 `player.target`，`player.gd:_process()` 追该点，同时
`aim_dir` 取鼠标位置。结果是角色永远朝鼠标跑，无法「边退边打」。

目标：**三路解耦**

- 移动 → 按键（PC 物理键 + 屏幕方向键）
- 瞄准 → 鼠标位置（PC）／右侧触摸位置（移动端）
- 开火 → 左键（PC）／右侧按住（移动端）

设计依据：自我决定论之「胜任感」——把走位从瞄准里解放出来，玩家才能主动
控制风险距离；心流平衡上给中高阶玩家留出操作上限，同时保留四向按键的低门槛。

## 2. 输入映射表

| 动作 | PC | 移动端 |
|---|---|---|
| 上移 | `W` / `↑` / 屏幕 W 按住 | 左下 W 按住 |
| 下移 | `S` / `↓` / 屏幕 S 按住 | 左下 S 按住 |
| 左移 | `A` / `←` / 屏幕 A 按住 | 左下 A 按住 |
| 右移 | `D` / `→` / 屏幕 D 按住 | 左下 D 按住 |
| 斜向 | 任意两键同按，向量归一化 | 同左 |
| 瞄准 | 鼠标位置 | 右半屏触摸/拖拽位置 |
| 开火 | 鼠标左键按住 | 右半屏按住 |
| 切武器 | `1`–`4` | 暂不提供屏幕键（见 §6） |
| 换弹 | `R` | 同上 |

**移动模型**：由「追逐目标点」改为「方向向量 × speed × delta」，按住持续移动、
松开即停，无惯性缓动。速度沿用角色增益 `speed = 260 × char_speed_mult`。

**合成规则**：`mv = 键盘向量 + 屏幕按键向量`，若 `|mv| > 1` 则归一化。
两来源可叠加，斜向不会比直线快。

## 3. 屏幕方向键布局

定位：左下角，锚点 `(0,1,0,1)`，随窗口缩放贴边。

```
   容器 240×180（距左 20 / 距下 20）
        [ W ]              (82, 0)
   [ A ][ S ][ D ]        (0 / 82 / 164, 92)
   单键 76×76
```

- 容器 `mouse_filter = IGNORE`，单键 `STOP`
- 按下态 `modulate = #FFC747`，松开恢复白色
- 命中区 76×76 逻辑像素，高于 44px 可访问性下限
- 仅 `state == "playing"` 可见；菜单/登录/结算隐藏并清空所有按下态

## 4. 交互状态与边界

| 场景 | 期望行为 |
|---|---|
| 按住 W + D | 右上 45° 匀速，速度不超上限 |
| 按住方向键同时鼠标瞄准 | 移动与朝向完全独立，可后退射击 |
| 松开按钮 / 移出按钮后松开 | 立即停止移动，不残留方向 |
| PC 点击左下方向键 | 移动生效，**不触发开火**（区域过滤） |
| PC 在方向键内按下、键外松开 | 开火状态正确复位，不卡持续开火 |
| 移动端触摸左下方向键 | 不参与瞄准/开火（左 45% 区域过滤） |
| 移动端右半屏按住并拖动 | 瞄准跟随手指，持续开火 |
| 移动端松手（任意位置） | 立即停火，瞄准方向保留最后一帧 |
| 切到结算 / 返回菜单 | 方向键隐藏、按下态清空、停火 |

## 5. 视觉与文案

- 按键文字直接用 `W/A/S/D`，与物理键帽一致，零学习成本
- HUD hint 改为：
  `WASD/方向键或左下按键移动 · 鼠标瞄准 · 左键开火 · 1-4 切武器 · R 换弹｜手机：右侧触摸瞄准并开火`
- 不新增美术资源，沿用现有 Theme / simhei 字体与 Button 默认样式

## 6. 已知取舍（本次不做）

- 移动端暂不提供「切武器 / 换弹」屏幕键：远程空仓会自动换弹、近战无弹药；
  若后续 Playtest 显示切枪需求强烈，再补右侧按钮组。
- 不做模拟量虚拟摇杆：四向 D-pad 在竖屏小尺寸下命中更稳。
- 不改变角色朝向绘制逻辑，武器仍按 `aim_dir` 绘制。

## 7. 验收标准

1. PC：仅按 WASD 能移动，鼠标移动只改变朝向、不带动位置
2. PC：按住左键后退（S + 反向鼠标）能持续开火，子弹朝鼠标方向
3. PC：鼠标按住屏幕方向键能移动且不开火，松开立即停
4. 移动端：左下方向键移动、右半屏触摸瞄准并开火，互不干扰
5. 菜单/登录/结算界面不出现方向键，不残留移动或开火
6. Web 导出后双端行为一致，手机虚拟键盘仍可输入用户名

## 8. 部署约束

改 `.gd` 后必须重新导出 Web 并提交 `index.pck` + `index.html` 再 push，
否则 Godot 里能玩、线上仍是旧版。导出预设已开启
`html/experimental_virtual_keyboard`，重导会自动带上 `experimentalVK:true`，
**无需手动改**。`index.wasm.gz` 由 Netlify build command 自动重生成，
无需手动同步。
