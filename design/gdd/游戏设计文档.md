# 《奶龙大胃王》游戏设计文档 (GDD)

## 1. 核心循环 (Core Loop)
- **动词：吞 (Eat)**。移动奶龙 → 吞食比自己小的鱼（体型 + 成长量）→ 变大、加分；被更大的捕食者吞 → 结束。
- **心流**：体型成长提供「胜任感」；难度梯度 + 关卡进阶维持「挑战-技能」平衡。

## 2. 系统拆解
| 系统 | 规则 |
|------|------|
| 吞噬成长 | `player.radius > 对方*1.15` 可吞；成长量 `= 1.4 + 半径*0.045`；加分 `10 + int(半径)` |
| 难度 | 简单/普通/困难，参数化：捕食者概率(0.3/0.45/0.6)、速度、追猎倍率(1.0/1.12/1.3)、生成间隔(0.55/0.45/0.35s)、入场费(20/30/40) |
| 关卡进阶 | 单局内 3 关自动进阶；达标分(300/800/1600)切主题背景；第 3 关达标 = 通关；每深一层捕食者 +10% |
| 捕食者 AI | 进入追猎范围(300/430/560px)后朝玩家加速，速度 = 基础 × 追猎倍率 |
| 奶龙币经济 | 每日签到 +100；入场费按难度；答题 +20/题（上限 8/日，币不足且已签到的兜底漏斗） |
| 皮肤 | 奶黄/青草/蜜桃，代码绘制换色（菜单可选） |
| 音频 | 程序化音效（吃=上扬、死=下行）+ 五声音阶循环 BGM（零素材） |
| 最高分 | `best_score` 本地持久化，结算/菜单展示 |

## 3. 玩家心理 (MDA)
- **机制**：成长、躲避、资源管理（币）。
- **动态**：爽快吞噬 + 紧张躲猎。
- **美学**：萌系、轻松、可控挑战。

## 4. 风险
- **IP 授权**：沿用市面「奶龙」IP，商用上架前须取得授权（用户已确认接受风险）。
