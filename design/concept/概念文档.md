# 《奶龙大胃王》游戏概念文档

> 阶段：Phase 1 概念孵化
> 起草：design-strategist（文策渊）方法论
> 署名说明：本运行环境子 Agent 通道不可用，由主理人按文策渊的方法论代笔；结论框架以策划标准为准，后续如有真实策划成员接入可无缝替换。

---

## 1. 电梯陈述（One-Liner）

一款面向移动端的萌系「大鱼吃小鱼」动作生存游戏：你操控一只圆润 Q 弹的奶龙，在糖果色海洋里吞掉比自己小的生物不断长大，躲避更大的捕食者，闯过层层关卡；而奶龙币与每日签到让你每天都有理由回来「再吃一口」。

---

## 2. 游戏支柱（Pillars）

1. **爽快成长（Growth Satisfaction）**：每一口都要「肉眼可见地变大」，尺寸即实力，正反馈拉满。
2. **萌即正义（Charm First）**：奶龙 / 奶娃的软萌造型与果汁感动效是第一吸引力，降低劝退阈值。
3. **低门槛高上限（Easy to Enter, Hard to Master）**：单手触控即可玩，但关卡与难度递进提供长期挑战。
4. **每日回来一口（Daily Habit）**：签到 → 领币 → 开局的轻量循环，把留存做成习惯而非任务。
5. **公平可得（Fair Economy）**：奶龙币靠签到与游玩稳定获取，付费是加速而非门槛。

---

## 3. MDA 框架分析

### Mechanics（机制）
- 核心动作：移动（虚拟摇杆 / 拖拽）、吞噬（碰撞体积小于自身即可吞）、成长（体型曲线随吞食量增长）
- 威胁：体型更大的鱼 / 捕食者 AI、环境 hazard（漩涡、毒水母）
- 资源：奶龙币（meta 货币）、关卡进度、分数 / 连击
- 规则：越吃越大 → 解锁可吞目标 → 失败条件（被更大者吞 / 血量耗尽）

### Dynamics（动态）
- 风险 / 回报取舍：追小鱼的安稳 vs 偷袭大目标的暴利高风险
- 雪球效应：早期领先 → 体型优势 → 滚雪球；逆风局的翻盘窗口
- 经济张力：每局扣币制造「每次开局都有代价」的稀缺感，倒逼玩家精打细算

### Aesthetics（美学 / 情感目标）
- 主要：Sensation（感官愉悦：软萌视觉 + 果汁音效）、Discovery（探索海洋）、Challenge（闯关）
- 次要：Submission（轻松解压的「无脑吃」时刻）

---

## 4. 玩家心理学

- **自我决定论（SDT）**
  - 自主（Autonomy）：自由选择路线、是否冒险吞大目标
  - 胜任（Competence）：尺寸成长与连击给持续掌控感
  - 关联（Relatedness）：排行榜 / 好友 / 社区（Phase 后期）
- **心流（Flow）**：难度档位 + 关卡递进调节挑战曲线，使技能与挑战持续匹配
- **Bartle 玩家类型适配**
  - Achievers（成就型）：关卡星评、收集图鉴
  - Explorers（探索型）：隐藏区域、稀有鱼种
  - Socializers（社交型）：排行榜、好友对战（后期）
  - Killers（杀手型）：高分竞速、吞噬排行
- **动词优先法（Verb-First）**：核心动词 = **吞（Devour）**；支撑动词 = 躲（Dodge）、长（Grow）、闯（Clear）。所有系统服务于「吞」的爽感。

---

## 5. 范围分层（Scope Tiers）

- **Must-Have（MVP）**：单角色奶龙、基础吞噬成长、3 关 × 3 难度、AI 小鱼 / 大鱼、奶龙币（每局扣费 + 每日签到 100）、本地最高分、基础 UI。
- **Should-Have**：多角色（奶娃等皮肤）、技能 / 道具、关卡星评、设置菜单、音效音乐、存档云同步。
- **Nice-to-Have**：好友排行榜、赛季活动、皮肤商城、剧情小章节、AR 拍照。

---

## 6. 视觉锚点（Visual Anchors → 给 art-director）

- 关键词：圆润（round）、果冻质感（jelly）、糖果色（candy / pastel）、大眼萌（big-eye kawaii）、Q 弹挤压（squash & stretch）
- 情绪板描述：像把「微信表情包 + 海底小纵队 + 史莱姆」揉在一起的柔软世界；水面透光、气泡上浮、软糖般的反光。
- 体型语言：角色越大，轮廓越圆、腮帮越鼓、表情越得意。
- 危险物语言：边缘用微微的尖刺 / 暗色描边提示「别惹我」。

---

## 7. 关卡与难度构思（初步）

- **关卡递进**：每关换主题海（珊瑚浅海 → 深海峡谷 → 熔岩热泉 → 极地冰海），引入新机制鱼（速度型 / 群居型 / 护甲型）。
- **难度档位**：简单（敌人慢、币耗低、容错高）/ 普通（基准）/ 困难（敌人快、币耗高、出现精英怪）。难度影响「每局奶龙币消耗」与敌人参数。
- **失败 / 重开**：被吞或血量耗尽 → 结算 → 消耗已扣 → 可再开。

---

## 8. 奶龙币经济闭环（初步）+ 风险

- **获取**：每日签到 +100（连续签到可递增，如 100 / 100 / 150 / 200…）、单局结算奖励、成就奖励。
- **消耗**：每局开局扣固定 / 随难度浮动的「入场费」（建议 简单 20 / 普通 30 / 困难 50）；皮肤 / 道具用币购买。
- **留存逻辑**：签到是零成本每日钩子；入场费制造「币快没了 → 明天再来领」的回流；连续签到递增进一步拉 7 日留存。
- **兜底漏斗（答题赚币）**：当玩家币耗尽且当日签到已用，提供「热门梗答题」入口，答对 +20 奶龙币（每日上限 8 次防刷），既续命又蹭热点，把流失边缘用户拉回循环。
- **⚠️ 授权风险（用户已确认接受）**：游戏名与形象沿用市面已有认知度的「奶龙」IP。用户决策：**保留奶龙 IP 命名**，正式名《奶龙大胃王》；**商用上架前须取得 IP 授权**（风险已确认，非阻断项，但上线前必补）。
