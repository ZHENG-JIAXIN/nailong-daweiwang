# 技术架构设计

## 技术栈
Godot 4.2+（GL Compatibility），GDScript，竖屏 720×1280，目标 iOS / Android。

## 模块结构
- **GameManager**（autoload 单例）：奶龙币、每日签到、本地存档、题库(20)、最高分、难度/关卡参数无关的经济与持久化。
- **Main**（场景根 Node2D）：状态机(menu/playing/gameover)、UI 构建、鱼群生成、输入、音频接线、关卡进阶与横幅。
- **Player / Fish**（Area2D）：实体 + `CanvasItem._draw` 代码绘制。
- **AudioPlayer**（`class_name AudioPlayer`，Node）：`AudioStreamGenerator` 程序化音效与 BGM。

## 数据流
输入 → `Player.target` → `_process` 移动 → `area_entered` 吞噬判定 → 分数/成长 → `check_progress` 关卡进阶/通关；GameManager 持久化币/签到/答题/最高分。

## ADR
- **ADR-1 占位美术用代码绘制**：零素材、快速验证玩法；正式美术后续以资产替换（Phase 3）。
- **ADR-2 音频用 AudioStreamGenerator 程序化合成**：免素材、参数可控；接受合成音质感一般。
- **ADR-3 存档用 `user://` JSON**：轻量、可读、易调试；无加密，适合单机原型。

## 质量门
- **编译**：Godot 4.7 严格类型——变量一律显式类型，避免 `:=` 推断 Variant（曾导致整项目加载失败）。
- **运行验证（F5）**：菜单渲染、难度梯度、关卡进阶、皮肤换色、音效与 BGM 出声。
