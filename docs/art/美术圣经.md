# 《奶龙大胃王》美术圣经（视觉身份九节）

> 阶段：Phase 1 概念孵化
> 起草：art-director（林绘澄）方法论
> 署名说明：本运行环境子 Agent 通道不可用，由主理人按林绘澄的方法论代笔；视觉标准以美术方向为准，后续如有真实美术成员接入可无缝替换。
> 关联输入：design/concept/概念文档.md 第 6 节「视觉锚点」。

---

## 1. 视觉身份概述

- **定位**：软萌、治愈、果汁感（juicy）的糖果海洋。
- **目标情绪**：第一眼想捏、玩起来解压。
- **风格锚定**：原创「奶龙风格」萌系（规避现有 IP 授权风险，见概念文档第 8 节）。
- **一句话基调**：把「表情包 + 海底小纵队 + 史莱姆」揉在一起的柔软世界。

---

## 2. 色彩系统

- **主色（大面积柔色）**
  - 奶油黄 `#FFF3C4`
  - 奶蓝 `#BFE3FF`
  - 蜜桃粉 `#FFD6E8`
- **辅色**
  - 薄荷绿 `#C8F4D9`
  - 葡萄紫 `#D9C2FF`
- **危险色（克制使用，面积 < 10%）**
  - 暗珊瑚红 `#FF6B6B`（描边 / 警示）
  - 墨蓝 `#2B3A67`（阴影）
- **规则**：高明度、低饱和；危险用色仅作提示，不破坏整体甜感。

---

## 3. 形状语言（Shape Language）

- **通性**：圆角、无锐角、有机曲线；体积感靠「鼓胀」而非棱角。
- **体型编码**：角色越大 → 越圆 → 腮帮 / 肚子越鼓；玩家仅凭轮廓即可读出强弱。
- **危险物语言**：边缘微微尖刺 / 暗色描边，传递「别惹我」信号，与可爱体形成对比。

---

## 4. 角色设计原则（奶龙 / 奶娃系）

- **比例**：头身比约 1:1 ~ 1:1.5（幼态化），大眼、短四肢 / 鳍。
- **表情**：靠眼睛高光 + 嘴型 + 腮红表达；**得意 / 惊恐 / 满足**三态为必需。
- **主角可辨识点**：专属配色 + 头顶小角 / 呆毛，确保缩略图（icon）也能一眼认出。
- **状态映射**：吞噬瞬间腮帮鼓胀；成长时体型胀大 + 表情更得意。

---

## 5. 环境与场景

- **分层视差**：远景柔光、中景珊瑚 / 水草、近景气泡粒子。
- **关卡主题换色温与标志物**：
  - 珊瑚浅海（亮、暖）
  - 深海峡谷（暗蓝、幽）
  - 熔岩热泉（橙红、暖危险）
  - 极地冰海（冷白、清）
- **统一要素**：上浮气泡、水面透光、软糖反光，贯穿所有主题。

---

## 6. 材质与光影

- **果冻 / 软糖质感**：高光点 + 半透明边缘 + 轻微环境反射。
- **卡通打光**：统一「顶部柔光 + 底部环境色反弹」，无写实硬阴影。
- **可读性优先**：在移动端小屏下，轮廓与色块对比高于细节精度。

---

## 7. UI 视觉语言

- **形态**：圆角卡片、气泡按钮、奶油描边；字体用圆体 / 卡通体。
- **奶龙币图标**：金币 + 奶滴造型，强辨识、强统一。
- **人体工学**：信息密度低、单手可点；关键按钮触控区 ≥ 44px。
- **反馈**：按钮按压有轻微挤压回弹（与角色 juice 一致）。

---

## 8. 动效与表情（Juice）

- **吞噬**：目标缩小吸入 + 主角腮帮鼓一下 + 轻微挤压回弹（squash & stretch）。
- **成长**：阶段性「噗」地胀大 + 光圈爆发。
- **受击**：抖动 + 红闪 + 缩扁。
- **通用原则**：squash & stretch、ease-out 缓动、气泡粒子点缀；所有动效服务「吞」的爽感。

---

## 9. 可访问性基线（Basic）

- 危险物除颜色外，必须有**形状 / 描边**区分（色盲友好）。
- 关键文字对比度 ≥ 4.5:1。
- 提供「减少动效」开关（防眩晕 / 前庭敏感玩家）。
- Standard / Comprehensive 级可访问性矩阵在 **Phase 3 技术搭建**由美术 + 工程细化。
