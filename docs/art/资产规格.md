# 资产规格（Phase 3 · 角色替换）

## 目标
将代码绘制的占位圆形替换为 噜噜 / 奶龙 / 奶娃 三个角色形象，并支持在三者间切换。

## 资产清单
| 角色 | 文件 | 占位调色板 | 备注 |
|------|------|-----------|------|
| 奶龙 | `res://assets/characters/0.png` | 奶黄(1.0,0.85,0.4) | 默认角色 |
| 噜噜 | `res://assets/characters/1.png` | 青(0.6,0.9,0.7) | — |
| 奶娃 | `res://assets/characters/2.png` | 粉(1.0,0.75,0.85) | — |

## 规格
- 格式：透明背景 PNG；尺寸建议 256×256 或 512×512（近正方）。
- 绘制：以角色中心对齐，直径 = `2 × radius`，随吞噬成长等比缩放。
- 切换：菜单「角色」三选一 → `GameManager.selected_char`（按用户持久化）→ `player.apply_character(id)` → 加载对应贴图。
- 回退：`player.load_texture()` 找不到 PNG 时 `char_tex = null`，`_draw()` 回退代码绘制，保证无素材也能运行。

## 接入点
- `player.gd`：`apply_character(id)` / `load_texture()` / `_draw()`。
- `main.gd`：菜单角色选择器 `pick_char` → `GameManager.set_char`。
- 鱼群与其他元素仍用代码绘制（占位），后续可同理替换为贴图。

## 合规
IP 角色仅用于**非商用**同人/学习场景；正式商用前须取得授权，并使用已授权或自制素材。
