# 奶龙大胃王 — Godot 4 垂直切片（MVP）

> 阶段：Phase 4 垂直切片验证（核心循环已增强：难度 / 关卡 / 皮肤 / 音频）
> 引擎：Godot 4.2+（GL Compatibility）
> MVP 范围：**多用户 + 3 难度 + 3 关卡 + 3 角色 + 核心吞噬循环 + 程序化音频**
> 起草：engineering-lead 方法论（运行环境无子 Agent 通道，由主理人代笔；署名清晰，可无缝移交）

## 如何运行
1. 用 **Godot 4.2 或以上** 打开 `src/` 文件夹作为项目（导入 `project.godot`）。
2. 按 **F5**（或编辑器右上角 ▶ 运行）启动。
3. 移动端导出：在 Godot `项目 → 导出` 中添加 Android / iOS 预设，按官方向导配置（需 SDK / 签名）。

## 玩法
- **操作**：手指拖拽 / 鼠标移动 → 奶龙跟随移动。
- **吃小的**：碰到比自己小的鱼 → 吞掉 → 体型变大、加分。
- **躲大的**：碰到比自己大的鱼（蜜桃粉，会主动追猎）→ 被吞 → 游戏结束。
- 鱼群持续从屏幕边缘生成、漂移；随你变大，原本的"大鱼"会变成食物。

## 难度（菜单可选，影响入场费与敌人强度）
| 难度 | 捕食者概率 | 捕食者速度 | 追猎倍率 | 生成间隔 | 入场费 |
|------|-----------|-----------|---------|---------|--------|
| 简单 | 30% | 90–130 | 1.0x | 0.55s | 20 |
| 普通 | 45% | 130–180 | 1.12x | 0.45s | 30 |
| 困难 | 60% | 170–230 | 1.30x | 0.35s | 40 |

> 困难下深层关卡捕食者速度可超过奶龙，必须靠走位躲闪，无法单纯甩开。

## 关卡（单局内自动进阶，达标即过关）
| 关卡 | 主题 | 背景色 | 通关分数 |
|------|------|--------|---------|
| 1 | 浅海乐园 | 浅蓝 | 300 |
| 2 | 珊瑚浅滩 | 暖珊瑚 | 800 |
| 3 | 深渊秘境 | 深蓝 | 1600 |

- 达标后弹出过关横幅并切换主题背景；第 3 关达标即 **通关**。
- 每深入一关，捕食者概率与速度小幅提升（关卡缩放 +10%/层）。

## 皮肤（菜单可选，角色代码绘制换色）
- **奶黄**（默认）/ **青草**（绿）/ **蜜桃**（粉）。

## 音频（零素材，程序化合成）
- 吃鱼：清脆上扬短音；死亡：下行音效。
- BGM：五声音阶循环分解和弦（舒缓），菜单与游戏中常驻。

## 多用户系统（已实现）
- 启动进入登录/注册界面；不同用户名各自独立存档：`user://users/<用户>/save.json`，资产相互隔离。
- 每用户独立保存：奶龙币、签到、答题、最高分、所选角色；菜单内「退出登录」可切换用户。

## 角色与贴图（Phase 3 资产规格）
- 三个可切换角色：**奶龙 / 噜噜 / 奶娃**，菜单「角色」三选一（按用户持久化）。
- 已内置原创占位贴图（透明背景 PNG）：`src/assets/characters/0.png`(奶龙) / `1.png`(噜噜) / `2.png`(奶娃)，游戏直接加载；缺失时回退代码绘制占位。可替换为授权/自制素材。详见 `docs/art/资产规格.md`。

## 奶龙币经济（已实现）
- **每日签到 +100**：跨天进入游戏自动发放（本地存档 `user://save_data.json`）。
- **每局入场费**：随难度 20 / 30 / 40，点"开始游戏"时扣除；余额不足无法开局。
- **答题赚币（兜底漏斗）**：当币不够且当日已签到，菜单出现「答题赚奶龙币」按钮；20 题热门梗选择题库，答对 +20，每日上限 8 次（防刷）。
- 余额、签到日期、答题次数、总场次、最高分均本地持久化；`GameManager.reset_daily()` 可清零当日签到与答题计数（保留币/场次/最高分）。

## 文件结构
```
src/
├── project.godot        # 项目配置（主场景 / GameManager 单例 / 竖屏 720x1280）
├── game_manager.gd      # 奶龙币 + 每日签到 + 本地存档（autoload）
├── main.gd              # 状态机 / 难度·关卡·皮肤 / 鱼群生成 / UI / 输入 / 音频接线
├── player.gd            # 奶龙：移动 + 吞噬成长 + 3 皮肤换色 + 代码绘制
├── fish.gd              # 鱼：食物/捕食者 + 漂移 + 追猎 AI + 代码绘制
├── audio_player.gd      # 零素材程序化音频（吃/死音效 + 循环 BGM）
└── Main.tscn            # 入口场景
```
