# 角色贴图目录（Phase 3 资产规格）
把每个角色的 PNG 放进本目录，命名为：

- `0.png` → 奶龙（奶黄）
- `1.png` → 噜噜（青）
- `2.png` → 奶娃（粉）

要求：
- 透明背景 PNG，近正方，建议 256×256 或 512×512。
- 贴图以「居中对齐、直径 = 2×角色半径」绘制，并随成长缩放（见 `player.gd` 的 `const CHARACTER_TEXTURES` 预加载 + `Sprite2D` 子节点）。
- **描边轮廓**：角色经 `player.gd` 的 `OUTLINE_SHADER`（基于 alpha 的描边材质）自动生成统一外缘轮廓，非方形框，呈现游戏精灵质感；描边宽度约角色半径的 6%。
- 未放置贴图时，回退到 `player.gd _draw()` 代码绘制的带描边占位圆形。
- 注意：当前三张占位 PNG 右下角带有生成工具的**半透明水印/角标**，正式上线前应替换为无 watermark 的自制或授权素材。
- 仅可使用你拥有授权或自制的素材；本项目为**非商用同人作品**。
